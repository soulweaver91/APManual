# Jazz Jackrabbit 2 Manual

## What is a Manual game?
A Manual game is a custom game that an item list and a location list is set for, so that any game can be included in a multiworld game. In this case, the manual implementation is for the late 90s Windows platformer action game Jazz Jackrabbit 2. You'll manually mark locations checked, and you'll manually restrict what items you use based on the items you've been sent.

## Where is the settings page?
You may either use the Options Creator available through the Archipelago Launcher, or generate the options template and then create a custom options file based on the generated JJ2 manual template.

## What does randomization do to this game?
At the start of the multiworld, you may start without several movement and combat options usually available to you. Additionally, access to each level is restricted until you've received either the corresponding level key or enough progressive episode level keys. As a result, you'll likely end up playing the levels out of order and sometimes even multiple times to return to collect previously unavailable checks, whileas in normal play you would just clear the levels a single time in a set order.

## What is the goal of a Manual game when randomized?
The goal is to achieve a "Victory" condition, which is available in the location list in the client. In the Jazz Jackrabbit 2 manual game, you'll attain this once you've reached the end and triggered the level transition in every level available according to your options. While you're working on your own goal, reaching save points, completing levels, and reading the signs scattered in the levels (including the unmarked ones mostly containing jokes and such) act as your location checks.

## Which items can be in another player's world?
The following progression items can be shuffled into the multiworld:
- Level unlock keys, either as level-specific keys or as progressive episode-specific keys
- Permits to use the various weapons available to the playable characters
- Permits to destroy specific types of blocks, such as ammo destructible blocks, buttstomp blocks, and high speed blocks
- Access to special movement skills (buttstomp, sidekick, double jump, copter ears)

## What if I have items, unlocks, or locations that I'd like to not have randomized?
It's all manual. Just exclude them from either the item or location list. 

## How do I install the mod for a Manual game?
You don't. There is no mod. The tasks of marking locations as checked and limiting your items used based on items received is all performed by you (the player) while using the Manual client and its accompanying tracker.
